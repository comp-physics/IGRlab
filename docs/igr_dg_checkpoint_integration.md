# DG/IGR checkpoint integration

This checkpoint integrates the cumulative DG/IGR acceleration campaign into `dev` for review. Its integration source is `5499c0dad18af7940e614019825113f3f52d5906` (DG/IGR arithmetic unchanged from the scope-trim commit `b9921a3`), derived from `igr-volume-storage-opt` at `8853754c2253861833a5495e5b23e6f0820bd2db`; the refreshed `dev` target is `ea12d1ffb2bd3f260586dc74f551058fd6ba5649`, already an ancestor. No dev/main merge is performed by preparing this branch.

## Scope and configuration

The checkpoint retains device FP64 FGMRES/ordered MGS and cooperative coarse CG, original-current-equation FP64 residual certification, the reusable global TF32 spectral inverse, FP32 SIMT Euler tensor lines, Euler tensor faces and compact transport storage, coefficient reuse, tensor/compact IGR faces, spectral nodal transforms, and collocated/direct FP64 volume application. It also retains the conserved output synchronization, optional diagnostic policy, and previously validated curved-cell modal damping implementation. Modal damping and positivity limiting are disabled in the benchmark.

Accelerated backend selectors remain opt-in. State-interpolation reuse for proven identical quadrature layouts defaults on; ordinary FP64 implementation fixes and output/diagnostic corrections also affect the baseline. This is not a claim that every code change is inactive by default. Optional nonfinite and admissibility scans default off; mandatory solver residual acceptance remains active independently.

The selected global spectral backend is qualified here for one CUDA rank, p5 ordinary DG on a uniform positive axis-aligned affine Cartesian rectangle with the admitted natural or periodic scalar boundaries. This does not establish a general curved/nonuniform mesh, cylinder-hole topology, DGSEM/HDG or multi-GPU solver default. Local optimized kernels have their own broader component fixtures, but those do not generalize the whole spectral solver.

Integration removes unrelated HDG coupled/local-solve prototypes from the cumulative snapshot, restoring those files to `dev`. Shared SM90 build support, a DGSEM benchmark PTX register correction, and the ParaView linkage required by shared state views are retained. All DG/IGR/shared-reference and simulation arithmetic remains byte-identical to the measured cumulative checkpoint. The distinct HDG solver work stays in [PR #75](https://github.com/comp-physics/IGRlab/pull/75). Its DG device Krylov, cooperative CG and conserved-output changes are already included here; merging this checkpoint would require reconciling that overlap before subsequently merging #75.

The saving is **3,572.291721155 s**. Sampled peak process GPU memory was **39,506 → 18,708 MiB**, saving **20,798 MiB / 52.645168%**. This is a direct cumulative measurement, including fresh setup, normal VTK output and finalization.
